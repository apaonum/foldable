Regressions found and fixed during this run:

- `16b3737f`: the Bridge never saw the Fold flip (the web view sits out the root view's layout pass); a `UIHingeInteraction` marked it for layout.
- Follow-up: that still missed about 1 in 3 book → flat toggles (the region flips after the last hinge update). The `layoutSubviews` hook now reads the division regions inside the pass, so UIKit lays the web view out again on the flip; the hinge interaction is gone. 10/10 toggles delivered. ADR 0003.
- `0f65a4e2`: React hydration warning on `<html>` in the Next example.
- `4fa5f973`: the Next demo's Arrangements were 21 pt off the Fold (no `--foldable-arrangement-offset-x`).
- `8d80d2c9`: in Safari about 1 in 7 fresh loads in book rendered flat. Right after load the segments describe an older geometry (980 px against a 951 px viewport) and catch up ~120 ms later with no event; the web reader now re-reads every frame while stale (max 180 frames). 24/24 loads pass after.
- `aadb2c1a`: the Nuxt demo had the `:dir()` rewrite (Vite's default CSS target) and no Arrangement offset; fixed like the Next demo.
- `08c7c34e`: Next's CSS build rewrote `:dir(rtl)` into `:lang()` lists, so RTL Displace stayed on the right. Demo targets Safari 17+; documented in `docs/primitives.md`.
